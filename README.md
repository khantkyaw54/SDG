# まちぐる（Inside-Town）
### 地元のお店を発見し、街をもっと楽しもう！

## 1. アプリの概要

「まちぐる」は、近くのお店を検索したり、地域のお店を訪れたりすることができるWebアプリケーションです。

カフェ、レストラン、和菓子店など、さまざまなお店の情報を確認できます。

地域のお店との新しい出会いを通して、街の魅力を発見することを目的としています。

## 2. 主な機能

- **マップ機能：** 地図から近くのお店を探すことができます。
- **検索機能：** 地名・住所・カテゴリーからお店を検索できます。
- **お店詳細機能：** お店の写真や住所、紹介などを確認できます。
- **お気に入り機能：** 行ってみたいお店を保存できます。
- **訪問履歴機能：** 行ったお店を確認できます。
- **口コミ機能：** お店の口コミを投稿・確認できます。
- **スタンプラリー機能：** お店を訪問してデジタルスタンプを集めることができます。
- **来店チェック機能：** QRコードを読み取って来店を確認できます。
- **クーポン機能：** 利用できるクーポンや特典を確認できます。

## 5. アプリの起動方法

### ① リポジトリをクローンする

```bash
git clone https://github.com/khantkyaw54/SDG.git
```

### ② プロジェクトフォルダに移動する

```bash
cd SDG/Inside-Town
```

### ③ 必要なパッケージをインストールする

```bash
npm install
```

### ④ APIキーを設定する

`Inside-Town` フォルダ内に `.env` ファイルを作成し、GeoapifyのAPIキーを設定します。

```env
VITE_GEOAPIFY_KEY=your_api_key
```

※ `your_api_key` の部分に自分のAPIキーを入力してください。

### ⑤ 開発サーバーを起動する

```bash
npm run dev
```

### ⑥ ビルドする

```bash
npm run build
```

ビルドが完了すると、`dist` フォルダに公開用ファイルが作成されます。
